# Data

Download a small NYC Taxi Trip Records Parquet file from the [NYC Taxi & Limousine Commission trip record data page](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) and place it in `data/sample/`. Start with one Yellow Taxi monthly Parquet file; the ingestion step currently accepts Parquet files only.

Raw datasets and generated Bronze/Silver/Gold outputs are excluded from Git. Do not commit credentials or large source data.
